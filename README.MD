# ClipHub

เว็บไซต์โปรโมตคลิปวิดีโอ พร้อมระบบหลังบ้านแบบเดโม (HTML + CSS + JavaScript ล้วน ไม่ต้องติดตั้งอะไร)

## โครงสร้างไฟล์
- `index.html` โครงหน้าเว็บ
- `style.css` ดีไซน์ทั้งหมด
- `app.js` การทำงานของหน้าบ้านและหลังบ้าน

## ใช้งาน
เปิด `index.html` ในเบราว์เซอร์ได้เลย หรือโฮสต์ด้วย GitHub Pages (Settings > Pages > Deploy from a branch > main > / (root))

หลังบ้าน: กดปุ่ม "หลังบ้าน" แล้วล็อกอินด้วย `admin` / `admin123` (รหัสเดโม ควรเปลี่ยนใน `app.js` ตัวแปร `seed.admin`)

## ข้อจำกัด
- ข้อมูลและไฟล์วิดีโอที่อัปโหลดเก็บในเบราว์เซอร์ของแต่ละเครื่อง (localStorage / IndexedDB) ไม่แชร์ข้ามผู้ใช้
- การล็อกอินเป็นเดโม ไม่ปลอดภัยสำหรับใช้งานจริง
- ใช้งานจริงควรทำเป็นระบบเซิร์ฟเวอร์ เช่น Next.js + PostgreSQL + ที่เก็บไฟล์
- ใส่ลิงก์ YouTube / Vimeo / .mp4 ได้ที่หลังบ้าน เฉพาะวิดีโอที่คุณเป็นเจ้าของหรือได้รับอนุญาต
